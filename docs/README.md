## 一句话产品定义

通过易用的语音／文字访谈，把用户的工作经验变成技能摘要、可编辑下载的简历和求职资源，同时在其选择允许的用途下沉淀行业流程、问题与领域档案。

## 首轮默认范围

- 美国英语用户；35–50 岁为主要研究人群，不作为访问门槛，不从头像或毕业年份推断年龄。
- 优先测试物流、供应链及相邻运营岗位；这是聚焦实验的选择，尚无市场数据证明它最优。
- 背景与经验访谈 → 技能重评、简历和求职建议 → 复制／下载与福利领取 → 自愿选择课程、社区或专家回访。
- 网站允许用户拒绝研究授权并完整使用职业服务；研究收入不进入首轮盈利假设。
- 移动端优先；支持逐轮录音、转写检查和确认发送，始终保留打字路径。
- 完整履历来自用户自填、口述、粘贴或上传；LinkedIn 链接只保存，不读取。第一期不接 Apollo／Clay 或其他个人 enrichment。
- Muse 来源已提供为邀请码社区页面；先支持福利资源入口，有真实可发放权益时再启用发码。
- Jobright.ai 为用户拟洽谈的合作候选，具体权益尚未确认。
- 本地 LLM 使用用户指定的局域网中转站；实际密钥不写入文档或仓库。

所有时间、价格、转化率和样本量都是待检验的设计假设，不是已发生的数据或行业基准。
