# 本地 LLM 中转站：配置与验证

用户指定本地开发使用家中局域网中转站。已按用户提供的鉴权信息直接访问，没有把密钥写入文件。

- 用户地址规范化为 `http://192.168.1.156:8317`。
- OpenAI 风格接口基址为 `http://192.168.1.156:8317/v1`。
- `GET /v1/models` 返回 HTTP 200，共 **56 个不同的模型 ID**。
- 完整清单保存于 [model-inventory.json](./model-inventory.json)。这是本次会话的快照，不保证将来不变。

## 实际文本测试

通过 `POST /v1/chat/completions`，用不含个人资料的短提示要求回复 OK；最多请求 24 个输出 token，不使用流式输出。

| 请求模型 | HTTP | 返回内容 | 本次单次耗时 |
|---|---:|---|---:|
| gpt-6-luna | 200 | OK | 1.23 秒 |
| claude-sonnet-4-6 | 200 | OK. | 1.75 秒 |
| gemini-3-flash | 200 | OK | 1.23 秒 |

三个请求均有文本回答，返回的模型字段与请求名一致。以上只证明本次基本文本请求成功，不是性能排名、严格指令遵循评分或任务质量测试。不同模型的 usage 字段含义需核实，不能直接据此推算统一费用。

## 在应用中的使用

已加入 [.env.example](../.env.example) 与忽略实际环境变量文件的规则。模板不含真实密钥，应用尚未实现，因此这些配置尚未被运行时消费。

暂定候选分工：访谈和字段抽取先试 gpt-6-luna；简历改写先试 claude-sonnet-4-6；gemini-3-flash 作为同一网关内的备用候选。正式默认值根据访谈、事实忠实、英西语、结构化输出、响应时间和实际成本评测确定，不能仅凭名称判断质量或价格。

所有请求从应用服务端发出。浏览器不直接连接中转站、不接触密钥。主模型错误时最多进行有上限的同用途重试，再使用明确配置的同网关候选；仍失败就保留进度。不能静默把简历发往另一个未配置的外部供应商。

## 尚未验证

- 严格 JSON／schema、工具调用、流式输出和 Responses API。
- 长上下文、真实简历、图像输入、并发、配额与失败恢复。
- 专用语音转写、音频输入与语音合成。清单里未见明确的专用转写 ID，但这不能证明网关不支持该接口。

语音作为独立适配器。先核实网关的音频路径；如不支持，再配置本地转写或由用户确定的服务。不能因为聊天可用就把语音列为已完成。

## 本地与公开部署

该地址在用户局域网内。电脑或同网段后端可以访问；手机上的 HTTPS 网站应调用应用后端，由后端访问网关。公网云后端能否访问取决于实际网络连接，不能假设它可直达该私网地址。

公开发布前选择：让后端运行在能访问网关的环境，或部署经过配置的网络连接，或更换到用户指定的可达服务。当前没有开放路由器端口、配置隧道或改变网络访问权限。
